# Contributing to libID

Thanks for your interest in libID. We are in early development and are not yet
actively seeking external contributions; unsolicited pull requests may be
closed. This will change as the project matures.

## Terms

By opening a pull request you agree that your contribution is licensed under
both the MIT license and the Apache License, Version 2.0 — the same dual license
this repository is distributed under (see `LICENSE-MIT` and `LICENSE-APACHE`) —
without any additional terms or conditions.

Every commit must be signed off (`git commit -s`), certifying the Developer
Certificate of Origin, Version 1.1 (https://developercertificate.org): that you
wrote the contribution or otherwise have the right to submit it under these
licenses. The `Signed-off-by:` name and email must match the commit author.
Pull requests with unsigned or mismatched commits fail the automated DCO check
and cannot be merged.

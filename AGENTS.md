# Agent instructions

## Commit attribution

- When an AI coding agent materially assists with a commit, append an
  `Assisted-by:` trailer naming the agent, for example `Assisted-by: Codex`.
- Do not use `Co-authored-by:` for AI assistance; keep the human author and
  committer unchanged.
- Preserve any required `Signed-off-by:` trailer alongside the attribution.
